# CyberSecurity-AI Production Boundary

## Current Status

CyberSecurity-AI is a public MESIE cybersecurity pillar repository. The README positions it as a 200-career cybersecurity MCP stdio server for Grok, Claude, Cursor, Antigravity, and compatible MCP hosts.

## Safe Public Scope

This repository may safely publish:

- Defensive cybersecurity career taxonomy
- Workforce and learning-path intelligence
- Safe MCP server configuration
- Defensive SOC, IR, GRC, IAM, zero-trust, and threat-intelligence categories
- Public documentation and examples that do not enable abuse

## Restricted Scope

This repository must not publish:

- Exploit procedures
- Malware, persistence, evasion, or unauthorized-access workflows
- Private CHIMERIA implementation details
- Operational details that materially enable cyber abuse
- Compliance or certification claims without evidence

## Evidence Required Before Production Claims

Before claiming production readiness, this repo needs:

1. Import smoke test for the MCP server package.
2. Tool-list smoke test proving the advertised MCP tools exist.
3. README path normalization between `mcp-server/server.py` and `mcp_server.server:main`.
4. License file present if README advertises MIT.
5. Safe-output test for career search and invocation tools.
6. Release receipt with commit SHA, test results, and hash manifest.

## Relationship to CHIMERIA

CyberSecurity-AI is the public-safe cybersecurity intelligence lane. CHIMERIA is the private defense architecture lane. Public docs may reference CHIMERIA only as a protected private architecture surface unless a specific release boundary approves more detail.
