# CyberSecurity-AI Platform Marketing Pack

## Positioning

CyberSecurity-AI is a public-safe cybersecurity intelligence MCP for career mapping, defensive workforce readiness, SOC/IR/GRC/IAM planning, and platform-native assistant workflows.

It is designed to work across MCP-compatible environments while preserving a protected private bridge to CHIMERIA for approved private intelligence packets.

## Primary Audiences

1. **Developers and AI builders** who want a cybersecurity MCP they can plug into Cursor, Claude Desktop, Grok-style MCP hosts, and internal agent stacks.
2. **Cybersecurity teams** that need role mapping, skill taxonomy, onboarding, and defensive workflow language.
3. **Training providers** building SOC, IR, GRC, IAM, zero-trust, cloud security, or threat-intelligence curricula.
4. **Enterprise operators** that need a safe public cybersecurity intelligence layer without exposing private trunk architecture.

## Core Messages

- Public-safe cybersecurity intelligence for MCP hosts.
- Defensive career and capability taxonomy for SOC, IR, GRC, IAM, cloud security, and threat intelligence.
- Optional CHIMERIA bridge for approved private packets without exposing the private trunk.
- Built for multi-platform marketing: Claude Desktop, Cursor, Grok-compatible MCP clients, local terminals, demos, workshops, and enterprise pilots.

## Product Surfaces

| Surface | Use |

## Taglines

- Cybersecurity intelligence for every MCP host.
- Turn cybersecurity roles into live AI tools.
- Public-safe cyber workforce intelligence with a private defense trunk behind it.
- SOC, IR, GRC, IAM, cloud security, and threat intel in one MCP lane.

## Demo Script

1. Install the package locally.
2. Add the MCP config to a supported client.
3. Ask the client: `List cybersecurity careers for incident response.`
4. Ask: `Map IAM Engineer to safe platform use cases.`
5. Optional private demo: set `CHIMERIA_BRIDGE_MANIFEST` to an approved exported manifest and ask for bridge status.

## Public Boundary

CyberSecurity-AI is defensive and educational. It does not provide exploit instructions, malware workflows, unauthorized-access guidance, or private CHIMERIA trunk implementation details.
